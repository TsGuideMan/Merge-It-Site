Merge It Quick Start: Your First Presentation in 5 Minutes

Published on February 10, 2026 · Updated on October 11, 2026 · 5 min read · By Man Singh Rana

This guide walks you through generating your very first automated PowerPoint presentation with Merge It. By the end, you will understand the whole workflow and be able to repeat it for any spreadsheet.

On this page

  1. Install Merge It
  2. Prepare a sample spreadsheet
  3. Prepare a sample template
  4. Run the conversion
  5. Check the result
  6. What to do next

Step 1: Install Merge It

Download the Windows installer from the downloads page and run it. Alternatively, you can run the app directly from source:

git clone https://github.com/TsGuideMan/Merge-It.git
cd Merge-It
npm install
npm start

Merge It runs entirely offline on your computer. It does not require an account, a login, or an internet connection.

Step 2: Prepare a Sample Spreadsheet

Create a simple Excel file or CSV file with a header row and a few data rows. For this example, use four columns:

| Customer Name | Company      | Amount  |
|---------------|--------------|---------|
| Amit Sharma   | Kathmandu Co | 1250.00 |
| Sita Gurung   | Pokhara Ltd  | 890.50  |
| Ramesh Thapa  | Lalitpur Inc | 2100.00 |

Save it as customers.xlsx or customers.csv. The header names matter because they must match your template placeholders exactly.

Step 3: Prepare a Sample Template

Open PowerPoint and create a simple slide like this:

Customer: {{Customer Name}}
Company:  {{Company}}
Amount:   {{Amount}}

Save the file as template.pptx. Every placeholder is written with double curly braces and matches a column header from your spreadsheet.

Step 4: Run the Conversion

  1. Open the Merge It application.
  2. Choose your spreadsheet data file and your PowerPoint template.
  3. Select the worksheet and set the row range. For our sample, start at row 2 (skipping the header).
  4. Set the output name, for example Customer Reports.
  5. Choose the generation mode. For this example, select One PPTX per row.
  6. Click the generate action.

The app reads your spreadsheet, finds every placeholder in your template, and produces one presentation per row.

Step 5: Check the Result

Open the output folder. You should see three files, one for each data row, with the placeholders correctly replaced:

Customer: Amit Sharma
Company:  Kathmandu Co
Amount:   1250.00

If any placeholder was not replaced, it usually means the placeholder text did not exactly match the column header. Check spelling and capitalization, then try again.

Common first-run mistakes

  1. Starting at row 1 instead of row 2, which turns the header row into a slide.
  2. Placeholder text that does not match the column header exactly.
  3. Multiple placeholders placed in the same text run.
