Merge It Troubleshooting: 8 Common Issues and Fixes

Published on June 18, 2026 · Updated on October 11, 2026 · 6 min read · By Man Singh Rana

Most Merge It problems come from a small set of causes. This guide covers the eight issues you are most likely to hit, with a clear fix for each one.

On this page

  1. 1. Placeholder text is not replaced
  2. 2. The header row appears as a slide
  3. 3. Only some placeholders are replaced
  4. 4. Wrong or missing rows
  5. 5. Text overflows the slide
  6. 6. Special characters appear garbled
  7. 7. The app cannot read the file
  8. 8. The output folder is empty

1. Placeholder Text Is Not Replaced

Symptom: Your generated slides still show {{Customer Name}} instead of the actual value.

Cause: The placeholder text does not exactly match the spreadsheet column header.

Fix: Compare the placeholder and the header character by character. Check for:

  • Different capitalization, such as customer name versus Customer Name
  • Extra spaces before or after the text
  • Underscores versus spaces, such as Customer_Name
  • Curly braces that are actually smart quotes

The safest approach is to copy the header text from the spreadsheet and paste it into the placeholder.

2. The Header Row Appears as a Slide

Symptom: One of your slides contains column names instead of data.

Cause: The row range starts at row 1 instead of row 2.

Fix: Set the start row to 2 whenever your first row contains headers. This is the most common first-run mistake.

3. Only Some Placeholders Are Replaced

Symptom: Some placeholders work, others remain unchanged.

Cause: Usually a text run issue, or a genuine mismatch in the header names.

Fix: In PowerPoint, check the affected placeholder. If other text shares the same text run with the placeholder, split them. Then verify that the header name matches exactly.

4. Wrong or Missing Rows

Symptom: Some rows were skipped, or unexpected rows appeared.

Cause: Blank rows in the middle of the data, or an incorrect end row setting.

Fix: Clean the spreadsheet before converting:

  • Delete completely empty rows
  • Check that the end row matches your last data row
  • Watch for hidden filter rows that look empty but are not

5. Text Overflows the Slide

Symptom: Long values run off the edge of the slide or overlap other elements.

Cause: The template text box was sized for short sample values.

Fix: Resize the text box in the template and reduce the font size slightly. Test with your longest values before running a full batch. Avoid PowerPoint's autofit setting because it behaves inconsistently.

6. Special Characters Appear Garbled

Symptom: Names with accents, umlauts, or non-Latin characters look wrong in the output.

Cause: The spreadsheet was not saved as UTF-8, or the font does not support the characters.

Fix: Re-export the data file as UTF-8. Then choose a font in your template that supports the characters you need.

7. The App Cannot Read the File

Symptom: Merge It reports an error or shows no worksheets when you select a file.

Cause: An unsupported format, a password-protected file, or a file still open and locked in another program.

Fix: Close the file in Excel or PowerPoint, remove any password protection, and confirm the format is supported. Supported data formats include .xlsx, .xls, .xlsm, .xlsb, .ods, .csv, and .tsv. Templates must be .pptx.

8. The Output Folder Is Empty

Symptom: The generation completes but no files appear where you expected.

Cause: The output path was not set correctly, or the row range produced no data rows.

Fix: Check the output name and destination folder. Confirm the row range includes at least one data row. If the start row is greater than the end row, nothing is generated.

Still Stuck?

If none of these fixes solve your problem, report it on the GitHub issues page. Please include:

  • Your Windows version
  • The Merge It version you are using
  • Steps to reproduce the problem
  • A screenshot or the exact error message, if available

We aim to respond to issues within a few days.
