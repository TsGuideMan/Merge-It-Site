Merge It - Software Details

About
-----
Merge It is an offline desktop application designed to convert spreadsheet data into PowerPoint presentations. It allows users to select an Excel/CSV data file and a PPTX template, map sheet columns to placeholders such as {{Customer Name}}, and generate one PPTX per row or one combined presentation for all rows.

The app is built for quick business reporting, document automation, and repetitive presentation generation without requiring an internet connection. The current project is a local Electron-based desktop app and is targeted at Windows users.

Usage
-----
1. Prepare a spreadsheet file (.xlsx, .xls, .csv, etc.) with headers.
2. Prepare a PowerPoint template (.pptx) containing placeholders like {{Customer Name}}.
3. Open the Merge It application.
4. Choose the spreadsheet data file and the PowerPoint template.
5. Select the worksheet and set the row range.
6. Set the output name and choose the generation mode:
   - One PPTX per row
   - One PPTX for all rows
7. Click the generate action to create the output presentation files.
8. Save the generated file(s) to your preferred location.

Tips:
- Placeholders must match the exact column headers in the spreadsheet.
- Use one text run for each placeholder in the PowerPoint template.
- Start row should normally be 2 if the first row contains headers.

FAQ
---
Q: Does this app require internet access?
A: No. It is designed as an offline local desktop application.

Q: What file types are supported?
A: Excel formats (.xlsx, .xls, .xlsm, .xlsb, .ods, etc.) and CSV/TSV files are supported for data input. PowerPoint templates must be .pptx.

Q: Can I generate multiple slides or multiple files?
A: Yes. You can generate either a separate PPTX for each row or a single PPTX for all rows.

Q: Do the placeholders need to match the spreadsheet headers exactly?
A: Yes. The placeholder text should match the column name exactly, including spelling and case behavior expected by the template.

Q: Is the source code public?
A: Yes. The source code is available from the repository below.
