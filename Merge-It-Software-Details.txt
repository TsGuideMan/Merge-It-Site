Merge It - Software Details

About
-----
Merge It converts spreadsheet data into PowerPoint presentations. The Windows desktop app and browser version let users select an Excel/CSV data file and a PPTX template, map sheet columns to placeholders such as {{Customer Name}}, and generate one PPTX per row or one combined presentation for all rows.

The app is built for quick business reporting, document automation, and repetitive presentation generation without requiring an internet connection. The current project is a local Electron-based desktop app and is targeted at Windows users.

Browser version
---------------
The website includes a client-side browser version at app/index.html. It processes selected spreadsheets and PowerPoint templates locally in the browser; it does not upload them. Spreadsheet and ZIP libraries are included locally so the application can work offline after its files have been downloaded. Per-row output is provided in one ZIP archive, or all selected rows can be merged into one presentation.

To use the browser version, open app/index.html from a web server or the hosted website, select a spreadsheet and .pptx template, then create and download the output. The first row of the worksheet must contain unique column headers. Placeholders must match those headers exactly and stay in one PowerPoint text run.

The downloadable standalone browser bundle is built with BUILD_WEB_APP.bat and saved as downloads/MergeIt-WebApp.zip. The merge-engine tests can be run with node --test tests/merge-engine.test.js from this folder.

Advertising setup
-----------------
The hosted browser app, homepage, and downloads page have responsive Google AdSense placements. To enable them, enter the AdSense publisher ID and the four 10-digit ad-unit IDs in app/ads-config.js, then rebuild downloads/MergeIt-WebApp.zip with BUILD_WEB_APP.bat if you want to distribute the updated app. The publisher site must be approved and configured in AdSense. Ads are deliberately disabled for the standalone file:// bundle so local/offline file merging never requests third-party resources. Configure Google's required certified consent management platform for EEA, UK, and Swiss visitors before enabling ads for those regions. Without valid publisher and ad-unit IDs, no ad requests are made.

Usage
-----
1. Prepare a spreadsheet file (.xlsx, .xls, .csv, etc.) with headers.
2. Prepare a PowerPoint template (.pptx) containing placeholders like {{Customer Name}}.
3. Open the Merge It application.
4. Choose the spreadsheet data file and the PowerPoint template.
5. Select the worksheet and set the row range.
6. Set the output name and choose the generation mode:
   - One PPTX per row
   - One PPTX for all rows
7. Click the generate action to create the output presentation files.
8. Save the generated file(s) to your preferred location.

Tips:
- Placeholders must match the exact column headers in the spreadsheet.
- Use one text run for each placeholder in the PowerPoint template.
- Start row should normally be 2 if the first row contains headers.

FAQ
---
Q: Does this app require internet access?
A: No. It is designed as an offline local desktop application.

Q: What file types are supported?
A: Excel formats (.xlsx, .xls, .xlsm, .xlsb, .ods, etc.) and CSV/TSV files are supported for data input. PowerPoint templates must be .pptx.

Q: Can I generate multiple slides or multiple files?
A: Yes. You can generate either a separate PPTX for each row or a single PPTX for all rows.

Q: Do the placeholders need to match the spreadsheet headers exactly?
A: Yes. The placeholder text should match the column name exactly, including spelling and case behavior expected by the template.

Q: Is the source code public?
A: Yes. The source code is available from the repository below.
