Merge It Downloads

Merge It is an offline desktop application for Windows that converts spreadsheet data into PowerPoint presentations using Excel/CSV inputs and PPTX templates.

git clone https://github.com/TsGuideMan/Merge-It.git
cd Merge-It
npm install
npm start
